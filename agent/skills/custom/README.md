# Custom Skills

Hand-authored or locally adapted skills with no clean upstream mirror target.

## Skills

- `critical-ai-partner/` — engineering judgment and pushback workflow.
- `fable5/` — curated workflows extracted/adapted from Fable-style prompt research.
- `workspace/` — local date-prefixed branch/worktree setup.
- `skill-helper/` — local helper for adding/syncing skills, categories, manual-only policy, and validation.

## Policy

Keep local skills here. If a skill has a maintained upstream repo, place it under `agent/skills/<upstream-owner>/` with a source-level README instead.
